Question sets

A question set is a frozen snapshot of the approved bank. Classes practise from a set, never from the live bank, so editing or rejecting a question later does not change a set that already exists. Only deleting a question removes it from the sets it was in.

Frozen means frozen

There is no edit for a set. A snapshot that could change would say nothing about what a class was actually served.

Giving students new questions

Freeze a new set, then switch the class to it on Classes. Runs already started stay on the set they began with.
