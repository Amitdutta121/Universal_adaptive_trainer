Fixed adaptive mechanism

This design is settled and is not to be redesigned without an explicit instruction.

  • Topic mastery is tracked with BKT.
  • Every subtopic carries a weakness value; all weaknesses start equal.
  • Weakness-weighted roulette selection chooses the next subtopic — exploiting weak areas while still exploring.
  • BKT topic mastery sets difficulty: low → easy, medium → medium, high → hard.
  • A question is selected by desired subtopic, desired difficulty, then priority.
  • A served question drops to lowest priority, so unused questions are preferred; reuse resumes once the others have been used.
  • Scores run 0–100. Testable programming questions score passed_tests / total_tests × 100; naturally discrete questions score 0 or 100.
  • A score updates the topic's BKT state and the weaknesses of the question's subtopics.
