How the next question is chosen

This mechanism is settled; see ADR-041 for the rules it left open.

  • Every subtopic carries a weakness; all start equal, so the first draw is uniform.
  • Weakness-weighted roulette picks the subtopic — exploiting weak areas while still exploring. A mastered subtopic keeps a small floor, so it can always come back.
  • That subtopic's topic BKT mastery sets the difficulty: low → easy, medium → medium, high → hard.
  • Within the cell, a question this student has not answered comes first, then highest priority, then least used.
  • A served question drops to lowest priority, so another is preferred next time; reuse resumes once the others have been used.
  • Scores run 0–100. Testable programming questions score passed_tests / total_tests × 100; discrete questions score 0 or 100.
  • One score updates the topic's BKT state and the weakness of every subtopic the question was tagged with.
